# Smart Login System

A client-side authentication practice project with registration, sign-in, a protected welcome page, validation, and session persistence through browser storage.

## Features

- User registration with validation
- Duplicate email checks
- Login credential verification
- Personalized welcome screen
- Logout flow
- Browser-based persistence with local storage

## Built With

- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript
- Local Storage API

## Run Locally

~~~bash
git clone https://github.com/MohamedSamirMoussa/smart-login.git
cd smart-login
~~~

Open index.html in a browser.

## Security Note

This repository is an educational front-end demo. It stores data in the browser and must not be used as production authentication. A production system should validate credentials on a secure server and store hashed passwords in a database.
